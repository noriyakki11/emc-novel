# 주문서 결과 효과음

로컬 메이플스토리 KMS 1.2.43 클라이언트의 `Sound.wz/Game.img`에서 추출한 원음입니다. Kenney CC0 자산에 포함되지 않습니다. 원본 저작권은 NEXON에 있습니다.

| 파일 | 원본 노드 | 사용 시점 |
|---|---|---|
| maple_scroll_success.mp3 | EnchantSuccess | 4단계 철벽·광전사 각각의 결과가 켜지는 순간 |
| maple_scroll_failure.mp3 | EnchantFailure | 1단계 팍(650ms), 2단계 펑(950ms) 충격 순간 |

- 원음의 높낮이·재생 속도는 유지하고 재생 음량만 조절합니다.
- 원본: KMS 1.2.43 클라이언트의 `Sound.wz`
- 추출: 기존 WzComparerR2.WzLib를 이용한 `tests/export_scroll_sounds.ps1`.
- 원본 클라이언트 파일은 수정하지 않았습니다. 웹 미리보기에서 외부 서버 호출 없이 사본을 재생합니다.
